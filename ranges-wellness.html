alert rules — compared to each athlete's own baseline
The app learns a personal baseline for every athlete in each wellness area (their average from previous check-ins). Alerts fire on negative change from that baseline — not on fixed scores — so a naturally sore athlete doesn't trigger false alarms, and a decline in a usually-fresh athlete is caught early.
Until then, no baseline alerts fire for that athlete (chat requests still alert immediately).
Also fire a red alert on any single score of 5, regardless of baseline
Include session RPE (training load) in baseline alerts

google sheets sync
Follow RANGES_Wellness_Setup.md to create the Google Sheet + Apps Script (about 10 minutes, free). Sync makes check-ins visible on every device and turns on automatic alert emails. Without it, data stays on each device only.
data
Demo data adds sample athletes & check-ins so you can preview the wellbeing screen (one athlete declines, to show alerts). Clear removes everything from this device (and the sheet if sync is on). CSV export lives on the wellbeing screen — admin has no access to athlete data.
